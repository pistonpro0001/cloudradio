# Scratch Cloud Radio Backend

Backend for my Scratch cloud radio project thingy.
Uses ScratchAttach, Flask, threading, and a reconnect loop to sync audio progress to Scratch.

This repo exists mostly so I can showcase the architecture.
Curious to see why and if the radio is down? Visit <https://cloudradio.onrender.com/> for more info on what's happening.

Check the frontend out **[here](https://scratch.mit.edu/projects/1314420436/)**.
